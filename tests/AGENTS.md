# Scientific test ownership

Runtime tests and numerical probes for this workspace run on XTX in its supported
environment, never on the user's Mac. Do not repair/install local science stacks.

For every added test, name its observable contract, credible failing regression,
stronger existing proof and actual production owner. Keep one primary owner per
contract. Another layer needs a distinct transport/lifecycle risk.

Use independent physics/algebra oracles, synthetic assets and real backend parity.
Do not derive expected values from the same helper/renderer under test. Source
inspection is retained only for genuine architecture/release contracts.

Import the real package. Never inject fake modules under its real names or hide
package errors behind broad optional-runtime skips. Optional dependency absence
must be explicit; a pinned backend import failure is a failure.

Before retiring a complete suite, record every declaration R/F/C/D, transfer its
scientific keepers and reconcile exact baseline/candidate cases. Failed tests
are not deletion candidates merely because they fail. Defect fixes need intended
baseline-red/candidate-green proof on the same harness.

Protect units/flux/magnification, covariance/nuisance projection, current sampling,
signed detection, input identity, real spawn/resource lifecycle, JIT/gradient and
reference/JAX parity. Separate numerical/science changes from API refactoring.
